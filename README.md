# cardnews-assets

카드뉴스 이미지 호스팅용 저장소.

Instagram / Threads 콘텐츠 발행 API 는 **로컬 파일 업로드를 지원하지 않는다** —
이미지가 공개 URL 로 접근 가능해야 하고, Meta 서버가 그 주소로 직접 받아간다.
그래서 발행 대상 이미지를 여기에 올려 `raw.githubusercontent.com` 주소로 넘긴다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `issue-ledger/` | 「AI는 문제를 잘 찾습니다 — 그 다음이 문제입니다」 10장 (2026-09) |

## 규격

1080×1350 (4:5) PNG. 인스타 캐러셀 최대 10장, 스레드 캐러셀 최대 20장.

## 주의

- **공개 저장소다.** 발행 예정인 이미지만 올린다. 내부 자료·미공개 원고를 두지 않는다.
- 파일명을 바꾸면 이미 발행된 글의 이미지가 깨질 수 있으니 **덮어쓰지 말고 새 폴더**를 쓴다.
